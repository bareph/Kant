### 레포지토리 만들기
레포 만들기

1단계(위치 local 폴더/터미널)

mkdir [레포] : 로컬에 레포지토리 폴더를 생성한다.

cd [레포] : [레포] 폴더에 들어간다.

git init : git을 초기화한다.(초기 git을 생성한다.)

2단계(위치  Github)

New repository 생성 : 레포지토리를 생성한다.(레포 이름, 내용, 공개 여부, README.md 여부)

collabo 설정 : setting에 들어가 협업 인원을 추가한다.(추가는 Github이 등록된 아이디로)

3단계(터미널)

git remote add [알리아스/origin 같은] [Github URL] : 깃허브 주소를 알리아스 명칭으로 연결한다.

git pull [알리아스] main : Github에 생성된 레포를 내 로컬에 pull한다.

---
### 충돌 해결하기
#### 가정) 같은 Line의 내용을 수정하여 팀원이 먼저 main에 push 했을 때

1. 우선 push가 실패한 경우 먼저 Github를 pull한다.
2. 충돌이 났다면, 필요한 부분을 남기고 문제가 되는 부분을 삭제한다.
3. 이후, git add . → git commit -m ~ → git push 순서로 진행한다.
(기존  내가 push하려는 commit 이력은 지워지고 staging 상태에서 내려간다. 그러므로 stage에 올리는 상태부터 다시 시작해야 한다.)
