### for문
혼자서 좀 연습을 많이 해봤다. 제일 부족한 부분이 for문과 if문이고 이게 제일 중요한 두 파트이기 때문에

기본적으로 같이 학습한 것 말고 LLM에 문제 제출해달라고 요청하면서 한 문제로 여러 유형의 상황을 만들어서 해결해봤다.

```python
inventory = [
    ('Potion', 50, 5),
    ('Sword', 300, 1),
    ('Shield', 200, 2),
    ('Arrow', 5, 40)
```
inventory 리스트를 만들어서 몇 가지 유형의 문제를 만들었다.
```
1. 조건문으로 특정 값 이상에 별표 표기해보기

2. 가격에 따른 expensive, cheap 리스트 생성

3. expensive 갯수 세기

4. 최댓값 찾기
```

물론 힌트도 같이 제공되고 if문도 사용했지만 어떠한가 내가 스스로 고민해서 해결을 해봤다는 게 중요하고 시도할 수록 정답에 가까워진 것이 중요하지 않겠는가?

오늘은 답을 찾아 과정에서 재미도 느끼고 오류 문구를 읽어 해석해보면서 어떻게 오류가 발생했는지도 확인해보려고 노력하여 즐거운 시간이였다.

```

Y = 현재 shell을 코드(code/python) 형식으로 변환
```
