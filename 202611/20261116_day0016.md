docker compose ps

### postgresSQL
- CREATE DATABASE `a`; : `a` 데이터 베이스 생성
- CREATE TABLE `b`(); : `b`의 테이블 생성
    CREATE TABLE members
    (
        member_id   SERIAL      PRIMARY KEY,
        name        VARCHAR(30) NOT NULL,
        gender      CHAR(1)     NOT NULL,
        birth_year  SMALLINT    NOT NULL,
        phone       VARCHAR(20),
        email       VARCHAR(50),
        region      VARCHAR(10),
        join_date   DATE        NOT NULL
    );

- INSERT INTO `b` VALUES `~` : b의 테이블 컬럼의 값을 넣음
    INSERT INTO courses (sports_id, course_name, level, class_days, start_time, capacity, fee)
    VALUES (1, '수영 초급 새벽반', '초급', '월수금', '06:00', 20, 70000);  

- SELECT * FROM `b` : b 테이블의  모든 데이터를 보여줌
