CASE WHEN ~ END AS `별명` 

```sql
SELECT name, birth_year,
        CASE WHEN birth_yaer <= 1960 THEN '할인'
            WHEN birth_yaer >= 2000 THEN '청소년'
            ELSE '일반'
        END AS "요금 구분"
FROM members
LIMIT 10;
```

ORDER BY `column1`:  오름차순으로 정렬

ORDER BY `column1, column 2` : 칼럼 순서대로 오름차순으로 정렬

ORDER BY `column` **DECS** :  내림차순으로  정렬

NULL 데이터가 존재하는 경우

```sql
SELECT name, email 
FROM members
ORDER BY email DESC, name;
```

FROM enrollments
