### docker
사실 오늘 배운 건 어려운 건 없었다.

다만, 모르면 안될 거 같다. 그리고 가장 헷갈리는 부분은

이미지마다 run하는 방법이 다르다는 것...

이런 좀 벌써부터 두렵다.

#### 이미지 관리
1. **이미지란?** 프로그램 설치본 / python's class의 역할 / 게임 칩의 역할
| 명령어 | 의미 |
| --- | --- |
| `docker pull 이미지` | Docker Hub에서 이미지 내려받기 |
| `docker pull ubuntu:버전` | 태그로 특정 버전 받기 (콜론 뒤에 공백 없이) |
| `docker image ls` / `docker images` | 이미지 목록 (둘은 같은 기능) |
| `docker rmi 이미지` | 이미지 삭제 (그 이미지로 만든 컨테이너를 먼저 지워야 함) |

---
#### 컨테이너 상태 관리
1. **컨테이너란?** 이미지를 실행한 결과물 / class's instance / 실행되고 있는 게임
| 명령어 | 의미 |
| --- | --- |
| `docker ps` | 실행 중인 컨테이너만 보기 |
| `docker ps -a` | 정지된 것 포함 전부 보기 |
| `docker stop 이름 또는 ID` | 컨테이너 중지 |
| `docker rm 이름` | 컨테이너 삭제 (중지된 것만 가능) |
| `docker rm -f 이름` | 실행 중이어도 강제 삭제 |

2. **컨테이너를 진입하기 위해서는?**
```bash
docker run -it --name 컨테이너이름 이미지이름 셸이름
# 예: docker run -it --name my-ubuntu ubuntu bash
```
- `-i` : 입력을 가능하게 유지(interactive)
- `-t` : 터미널을 제공한다.

**`docker start -ai 컨테이너이름`**: 멈춘 컨테이너를 다시 켜서 접속. `run`은 매번 새로 만들고, `start`는 기존 것을 다시 켬.

#### nginx(엔진x라고 부르는) 웹서버
1. **nginx는 뭐하는거야?** : 사용자의 웹 요청을 받아서 처리해주는 프로그램
```bash
docker pull nginx
docker run -d --name my-webserver -p 8080:80 nginx
```
- `-d` : 백그라운드에서 실행(datched)
- `-p 8080:80` : 내 컴퓨터 포트(8080)에서 컨테이너 포트(80)으로 연결

만약 옵션을 모르겠다면?

| 명령어 | 의미 |
| --- | --- |
| `curl 주소` | 터미널에서 웹 요청을 보내 응답 확인 |
| `netstat -ano | grep :8080` | 8080 포트를 누가 쓰는지 확인 (Windows는 `findstr`, 맥/리눅스는 `lsof -i :8080`) |
| `docker exec -it my-webserver bash` | 실행 중인 컨테이너 안으로 접속 (나올 때 `exit`) |
| `cd /usr/share/nginx` | nginx 웹 파일 폴더 (실제 페이지는 `html/` 안) |
| `docker logs 이름` | 지금까지의 로그 출력 |
| `docker logs -f 이름` | 실시간 로그 (`-f` = follow, 종료 `Ctrl+C`) |

<aside>
💡

`run -it`은 새 컨테이너를 만들며 진입, `exec -it`는 이미 실행 중인 컨테이너에 추가로 접속

</aside>

#### 환경 변수와 DB 컨테이너
**MySQL**
```bash
docker run -d --name my-sql -e MYSQL_ROOT_PASSWORD=비밀번호 -p 3306:3306 mysql:버전
docker exec -it my-sql mysql -uroot -p
```
- `-e` : 컨테이너 안에 환경 변수 전달
- `-uroot -p` : root 사용자로 접속, 비밀번호 입력 후 SQL 프롬포트 진입
| SQL | 의미 |
| --- | --- |
| `SHOW DATABASES;` | 데이터베이스 목록 조회 |
| `CREATE DATABASE 이름;` | 데이터베이스 생성 |

**PostgreSQL + volume**
```bash
docker run -d --name my-pg -e POSTGRES_PASSWORD=admin1234 -p 5432:5432 -v pgdata:/var/lib/postgresql/data postgres
```
- 컨테이너를 삭제하면 안의 데이터도 사라짐 → **volume**은 데이터를 컨테이너 밖에 저장해 보존
- `-v 볼륨이름:컨테이너경로`
