## 1. SGDRegressor `NotFittedError`

### 원인
```python
sgd.partial_fit               # 괄호가 없어 실행되지 않음
sgd.predict(X_train_scaled)   # 학습 전에 예측해서 에러 발생
```

### 해결
```python
sgd.partial_fit(X_train_scaled, y_train)
pred = sgd.predict(X_train_scaled)
```

- 메서드는 괄호를 붙여 호출해야 실행된다.
- 예측 결과를 다시 쓰려면 변수에 저장해야 한다.
- `partial_fit`은 이전 가중치에서 이어서 1 epoch 학습한다.

## 2. 단순 회귀와 다중 회귀 비교
- 단순 회귀: 특성 1개(`play_hours`)로 `xp` 예측
- 다중 회귀: `features`의 여러 특성으로 `xp` 예측
- 흐름: 데이터 분리 → 학습 → 예측 → 평가
- `X[["play_hours"]]`처럼 대괄호를 두 번 쓰면 2차원 형태가 유지된다.
- 특성이 많다고 테스트 성능이 항상 좋아지는 것은 아니다.

| 지표 | 의미 | 좋은 방향 |
|---|---|---|
| MAE | 오차 절댓값의 평균 | 작을수록 |
| MSE | 오차 제곱의 평균 (큰 오차에 민감) | 작을수록 |
| R² | 평균값 예측 대비 성능 (음수 가능) | 1에 가까울수록 |

## 3. `train_test_split`
```python
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42
)
```

- `test_size=0.25`: test 25%, `train_size`를 생략하면 train은 나머지 75%
- 반환 순서: `X_train, X_test, y_train, y_test`
- 인덱스 0, 2는 train, 1, 3은 test
- 변수 이름이 아니라 **반환 순서**대로 값이 저장된다.
- `X`와 `y`는 같은 행 기준으로 나뉜다.
- `random_state`를 고정하면 같은 데이터와 설정에서 같은 분할을 재현할 수 있다.
